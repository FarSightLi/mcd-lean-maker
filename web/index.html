    交给 AI 下单

    本页是固定快照，不下单。要用实时菜单并真正下单，需在本地 AI 工具（如支持 MCP 与 Skill 的 AI 编程助手/客户端）中配置麦当劳 MCP 并安装本 Skill。

    1. 添加麦当劳 MCP

      以 Claude Code 为例，在终端运行（Token 在 open.mcd.cn/mcp 登录控制台申请，详见 github.com/M-China/mcd-mcp-server，放进环境变量 MCD_MCP_TOKEN）：

      claude mcp add --transport http mcd-mcp https://mcp.mcd.cn \
  --header "Authorization: Bearer $MCD_MCP_TOKEN"

      其他客户端参照仓库 README 中的 JSON 配置（mcp-config.example.json）。

    2. 安装 Skill

      从仓库 github.com/FarSightLi/mcd-lean-maker 下载，把 skill/mcd-lean-maker 整个目录复制到你所用 AI 工具的技能目录（Claude Code 为 ~/.claude/skills/）。

      git clone https://github.com/FarSightLi/mcd-lean-maker.git
cp -r mcd-lean-maker/skill/mcd-lean-maker ~/.claude/skills/

    3. 说一句话

      用麦麦减脂助手 Skill，帮我在附近麦当劳到店自取：巨无霸（去巨无霸酱、吉士）+ 美式，预算 30 元、热量 600 kcal 以内，先给我确认卡再下单

      也可以在上方推荐方案或商品弹层里点“交给 AI 下单”，拿到当前搭配的话术。
