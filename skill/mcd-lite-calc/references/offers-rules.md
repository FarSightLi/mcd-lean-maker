# 优惠规则

- 每单只能使用一张优惠券;如果用户想用多张券,要拆成多单分别下单,不能在一个 `create-order` 里塞多张券。
- 门店维度可用券以 `query-store-coupons` 的实时返回为准,不要用 `available-coupons`(用户卡包里的全部券)直接当作当前门店可用。
- 菜单项的 `discountType` 为"随单购麦金卡优惠"时,`currentPrice` 已经是开通麦金卡之后的价格,不是原价,展示时要分别标出"原价"和"随单购价(需开卡)"。
- 麦金卡净价计算:净价 = 随单购价 + 卡费;卡费(月卡)在一单里只算一次,即使单内有多个支持随单购的商品。
- 实测示例(2026-10-14):麦辣鸡腿堡四件套原价 ¥57 → 随单购价 ¥28 + 麦金卡月卡(30天)¥19 = ¥47,比原价省 ¥10。`calc.py quote` 的 `verdict` 字段即给出"开卡省¥10"这类结论,只展示结论,不代用户点击开卡。
